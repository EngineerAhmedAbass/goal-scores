# ⚽ GOAL — نتايج الماتشات

برنامج تتابع منه نتايج ماتشات الكورة لايف: الدوري المصري، دوري أبطال أفريقيا، والدوريات الأوروبية الكبيرة — وأي دوري تاني تضيفه.

## 📱 تطبيق الأندرويد

**https://github.com/EngineerAhmedAbass/Test2/releases/download/goal-latest/GOAL-Scores.apk**

## أول مرة: مفتاح مجاني
البيانات جاية من [API-Football](https://www.api-football.com). محتاج مفتاح مجاني مرة واحدة:
1. اعمل حساب على https://dashboard.api-football.com/register
2. انسخ الـ API Key من الصفحة الرئيسية للحساب
3. افتح GOAL ← الإعدادات ← الصق المفتاح ← "حفظ واختبار"

المفتاح بيتحفظ على جهازك بس، ومش موجود في الكود.

## المميزات
- ماتشات أي يوم (أسبوع قبل وأسبوع بعد)، متجمعة حسب الدوري.
- فلتر: **بتاعتي** (دورياتك وفرقك) / **مباشر** / **كل الماتشات**.
- تحديث تلقائي للماتشات الشغالة + تنبيه "جوووول!" واهتزاز لما فريق في دورياتك يجيب جون.
- صفحة الماتش: الأحداث (أجوان، كروت، تبديلات، VAR)، الإحصائيات، والتشكيل.
- جدول الترتيب لكل دوري، بألوان المراكز (أبطال / هبوط) وآخر 5 ماتشات.
- تختار دورياتك وترتبها، وتضيف فرقك المفضلة بالنجمة.

## الخطة المجانية (100 طلب في اليوم)
التطبيق مبني يوفّر الطلبات:
- يوم كامل من الماتشات = طلب واحد، والأيام اللي فاتت بتتحفظ على الجهاز.
- التحديث المباشر بيجيب دورياتك بس، وبيشتغل بس والتطبيق مفتوح وفيه ماتش شغال.
- لو الطلبات قربت تخلص بيبطّأ لوحده، ولما تخلص بيعرض آخر نسخة محفوظة.
- عدد الطلبات الباقية ظاهر فوق.
